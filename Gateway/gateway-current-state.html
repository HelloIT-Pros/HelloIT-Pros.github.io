RAG Configuration

SettingValue
Content Extraction EngineMistral OCR — patched with image_limit: 0 so .docx / .xlsx / .pptx extract natively (May 2026)
Text SplitterCharacter with Markdown Header awareness
Chunk Size1,800 characters (was 3,200) — smaller chunks preserve negation clauses (e.g., "do not photocopy")
Chunk Overlap250 characters (was 400) — proportional ~14%
Chunk Min Size Target1,000 characters (was 0) — merges undersized fragments after markdown-header splitting
Embedding Batch Size50 — fast indexing for large documents
Full Context ModeOff — chunk retrieval only (cost and context control)
Hybrid SearchOn — BM25 keyword + vector semantic, BM25 weight 0.4 (was 0.5) — semantic dominates, keyword as tiebreaker
Top K10 chunks retrieved per query
Top K Reranker5 (was 3) — more signal for cross-doc questions
RAG System ContextEnabled (RAG_SYSTEM_CONTEXT=true) — retrieved context injected into system message; preserves KV cache across follow-up turns
Source CitationEnabled via system-prompt directive — model cites document and section verbatim
Follow-up / tag / autocomplete generationDisabled — addresses pilot feedback ("give me pause") and saves tokens

All RAG settings + system-prompt changes were arrived at by a structured evaluation framework. Full results in the Evaluation Results & Acceptance Report — baseline 56.9% → final 82.9% across a 30-question grounded benchmark, with every Prakash-flagged item resolved and all critical handover gates passing.

Prompt Library

Slash-command prompts available to all users. Invoked by typing the command in any chat.

/contract-summary Attach a vendor contract and receive a structured summary covering parties, scope, pricing, term dates, renewal conditions, and termination clauses.
/tenant-notice Draft a formal notice letter from Gateway Management to a tenant. Accepts inputs for tenant name, property, unit, and subject matter.

Project Timeline

May 17, 2026 Tuning Phase 4 (system prompt + retrieval) applied. Aggregate jumps to 79.3%.
May 17, 2026 Phase 4.5 — source cleanup. 4 broken .doc files re-OCR'd as .md. Community Listing .xlsx replaced with hand-authored .md including a "Managers Responsible for Multiple Properties" summary section (fixes Prakash's Q9). Aggregate to 82.9%.
May 21, 2026 Mistral OCR patch & content expansion. OpenWebUI loader patched with image_limit: 0 for native .docx / .xlsx handling. 12 additional Gateway docs uploaded (7 lease templates + 1 RFP + 4 vendor contracts).
May 22, 2026 Phase 9 — collection restructure. Single "Policies" catch-all split into 5 domain collections (HR/Staff, Tenant Operations, Leases, Property Reference, Business Development) alongside Agreements. Official RAG settings applied (CHUNK_MIN_SIZE_TARGET=1000, RAG_SYSTEM_CONTEXT=true).
May 23, 2026 Acceptance report published. Stakeholder-facing report mapping each Prakash item to current measured outcomes. All 7 handover gates passing. Recommendation: ship to pilot.
