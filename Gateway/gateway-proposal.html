Business Value to Gateway Management

The Gateway AI Assistant delivers a ChatGPT-like experience tailored specifically for your property management operations. Continuously enriched with your company's contracts, policies, and reference documents, it enables staff across all departments to access critical information instantly — without hunting through filing systems or waiting for someone to look something up.

Built on secure cloud infrastructure and powered by OpenAI, the Assistant lets your team search vendor contracts, reference the Employee Handbook, draft tenant communications, and review policies — all from one interface, accessible from any device.

  • Centralized knowledge hub for vendor contracts, policies, and operational documents
  • Conversational interface — ask questions in plain English, get accurate answers with source citations
  • Faster contract review — find terms, pricing, and expiry dates without reading every page
  • Consistent policy answers across all properties and departments
  • Prompt library for recurring tasks — tenant notice drafting, contract summaries
  • Reduced onboarding time — new staff can self-serve answers from day one
  • Scalable foundation for future AI initiatives across the portfolio

Key Features

Front-End (User Experience)

  • Clean, intuitive chat interface powered by OpenWebUI
  • New and saved conversations with full history
  • Knowledge collection search — attach contract or policy collections to any chat
  • Prompt library with slash commands (e.g. /contract-summary, /tenant-notice)
  • Responsive design for desktop and mobile
  • Branded as Gateway AI Assistant at ai.gwaffordable.com

Back-End (Data & Intelligence)

  • Secure authentication — admin-approved accounts only, no open registration
  • Retrieval-Augmented Generation (RAG) — answers grounded in your documents, with source citations
  • Hybrid search (BM25 keyword + vector semantic) for accurate contract term retrieval
  • PostgreSQL database for chats, embeddings, and knowledge collections
  • OpenAI embeddings (text-embedding-3-small) for document indexing
  • Stable session management and secure cookie handling

Infrastructure & Deployment

  • Containerized deployment via Docker Compose for reliability and easy updates
  • Hosted on dedicated VPS — isolated, single-tenant environment for Gateway
  • Caddy reverse proxy with automatic TLS (HTTPS) via Let's Encrypt
  • Hostinger daily automatic backups (4 snapshots retained)
  • HelloIT Pros manages all updates, monitoring, and document ingestion
