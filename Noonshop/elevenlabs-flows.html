01 · Overview

What is ElevenCreative Flows?

A node-based visual pipeline builder. Chain 50+ generative models (image, video, speech, music, sound effects) on an infinite canvas. Each node is independent — change one input, re-run only that node, leave everything else intact.

ElevenCreative Flows canvas — our Noonshop Architectural shot (Sofia × Dormann). Three nodes: Product Reference image → Sofia Anchor image + Text prompt → Nano Banana 2 generation.

Alpha product. Features are subject to change. No API yet (planned for a future release). Batch variations require manual re-runs — no automated variant loop as of April 2026.

ElevenCreative Flows is distinct from ElevenCreative Studio (which is a linear timeline editor). Flows = pipeline orchestration. Studio = final editing and track layering. The two are designed to complement each other: build in Flows, finish in Studio.

Key capabilities

Visual pipeline builder 50+ generative models Non-destructive iteration Nano Banana 2 supported Template library Batch variants (manual) Export to Studio API (planned)

05 · L11 · Safety Rule

TOS-Safe Prompting

ElevenLabs flags prompts that instruct the model to replicate a specific person's face. This is by design — it prevents deepfake-adjacent use. The fix: frame the task as styling, not replication. The identity comes from the reference image, not from the prompt text.

Rejected language: Any instruction that says "reproduce her face", "use the same face", "identity from image", "make her look like the person in image 2", or similar phrasing that explicitly directs face replication triggers the TOS flag.

❌ Rejected prompt framing

Will trigger TOS rejection
// DO NOT USE — TOS violation Reproduce the exact face of the woman in image 2, wearing the eyeglasses from image 1. // Also rejected: Use the identity from the portrait in image 2. Generate an image that looks exactly like the woman shown.

✅ Approved prompt framing (L11)

TOS-safe — identity comes from reference image, not prompt text
The woman shown in image 2 (the portrait reference), wearing the exact eyeglasses shown in image 1. // Then continue with the archetype prompt from the framework: [collection_token] [scene description] [lighting] [camera] [posture / expression]
Why this works: The prompt does not instruct the model to replicate a face — it simply references "the woman shown in image 2". The identity transfer happens implicitly through the image reference input, which is the intended use of reference images. This framing passes ElevenLabs' TOS check.
L11 — this is a framework-level rule. Every prompt written for ElevenLabs Flows must use the approved framing above. If you're adapting prompts from the content framework for a different runtime that doesn't have this constraint, the framing can be adjusted — but in Flows, always use the styling framing.
06 · Economics

Credit Model

Each node generation costs credits identical to the standalone tool pricing. Re-running a node triggers a new generation and a new charge.

What costs credits

  • Each Nano Banana 2 generation
  • Every re-run (new credits charged)
  • Upscale node (if used)
  • Each failed run is not charged

What doesn't cost credits

  • Uploading reference images
  • Editing the Text node
  • Saving the flow canvas
  • Viewing existing outputs
How to check before running: Hover over the Run button on a generation node — ElevenLabs displays the credit cost of that specific generation before you confirm. For 1K · 4:5 · Nano Banana 2, check the hover tooltip each session as pricing may change in Alpha.
Batch strategy: Since there's no automated batch loop yet, run one archetype at a time. Iterate prompt in the Text node, re-run the generation node, download the result. Keep costs predictable by running archetypes in sequence rather than spawning multiple flows simultaneously.

08 · How-to

Quick Start

How to run a new archetype shot using the existing pilot flow as a starting point.

1
Open the pilot flow

Navigate to Noonshop Architectural · Sofia × Dormann. Use it as a reference or clone it (Files → Duplicate) to create a new flow.

2
Update the Product Reference node

Click Replace on the Product Reference image node. Upload the front-view product image for the target collection (e.g. DO12410TPE-PO_FRONT.png for Dormann warm copper).

3
Update the Anchor node (new model only)

If running a different model (not Sofia), replace the anchor image with the target model's anchor file (e.g. amara_anchor_v1.jpg). Keep it the same if staying with Sofia.

4
Paste the archetype prompt into the Text node

Open the Content Framework, go to the Prompt Templates section, copy the target archetype prompt. Paste it into the Text node in Flows. Make sure it opens with the TOS-safe framing: "The woman shown in image 2 (the portrait reference), wearing the exact eyeglasses shown in image 1."

5
Run from the Nano Banana 2 output node

Click Run on the rightmost generation node. Hover to confirm credit cost. If you get a TOS error, check the prompt framing — see the TOS section above.

6
QA the output and download

Run the output through the QA Gate in the framework. If it passes, download via the ↓ icon and save to assets/output/pilot-[model]/[model]/[archetype]_[collection]_v1.png.

7
Document in the framework

Add the locked file to the framework's Files section with version number, prompt version, and any lessons learned. Update the pilot status callout.
