Share test

Proving a generated PDF reaches Outlook from this device before anything is built on top of it.

Environment

Run this twice: once in Safari, then again from the icon after Add to Home Screen. The installed case is the one in doubt.

The tests

1 and 2 differ only in whether the PDF exists before the tap. iOS can drop the user gesture across an await, so if 1 works and 2 does not, the real feature has to build the file before the Send button is live. 3 separates "files cannot be shared" from "PDFs cannot be shared". 4 confirms the PDF is valid when nothing is shared at all.
